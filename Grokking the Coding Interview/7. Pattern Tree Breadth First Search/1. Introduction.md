### <code style = "color:RED">1. Breadth First Search (BFS)</code>
 
**Breadth First Search (BFS)** technique to traverse a tree.
use a **Queue** to keep track of all the nodes,  space complexity of the algorithm will be O(W), where ‘W’ is the maximum number of nodes on any level.

In the BFS we have multiple method like the - preorder (NLR), in-order (LNR) and post-order (LRN)..

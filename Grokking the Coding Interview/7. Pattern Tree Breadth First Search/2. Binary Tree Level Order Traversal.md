## Maximum Sum of Contiguous Subarray of Size ‘k’

To solve the problem of finding the maximum sum of any contiguous subarray of size `k` in a given array of positive numbers, we use the **sliding window technique**. This approach reduces the time complexity from `O(n*k)` to `O(n)` by eliminating redundant summing of overlapping subarrays.

We start by calculating the sum of the first `k` elements as the initial window. Then, we slide the window forward one element at a time by **subtracting the element that's leaving the window** and **adding the new element that's entering the window**. At each step, we update the maximum sum if the current window sum is greater than the previous maximum. This technique ensures all possible subarrays of size `k` are considered efficiently.


```C++

#include <iostream>  
#include <cmath>  

using namespace std;  
  
int main() {  
    int arr[] = {2, 1, 5, 1, 3, 2};  
    int k = 3;  
    int n = sizeof(arr) / sizeof(arr[0]);  
  
    int sum = 0, ans = 0;  
  
    for(int i = 0; i < k; i++) {  
        sum += arr[i];  
    }  
    ans = sum;  
    for(int i = k; i < n; i++) {  
        sum += arr[i] - arr[i - k];  
        ans = max(ans, sum);  
    }  
    cout << ans;  
}

```

Problem Statement:-
Given an array of positive numbers and a positive number ‘S’, find the length of the **smallest contiguous subarray whose sum is greater than or equal to ‘S’**. Return 0, if no such subarray exists.

```
Input: [2, 1, 5, 2, 3, 2], S=7 
Output: 2 
Explanation: The smallest subarray with a sum great than or equal to '7' is [5, 2].
```

- To Solve this problem we have to first start adding the element in the sliding window until we get the sum greater than equals to `S`.

- After that we start sliding the window by add the next element and subtract the last element of the sliding window array and check the sub and the length of the sliding window.

- and we will do this to the last index of the actual array

```cpp

#include <iostream>
#include <vector>
#include <numeric>
#include <climits>

using namespace std;

int main() {
    int S = 7;
    int arr[] = {2, 1, 5, 2, 3, 2};
    vector<int> subarray;
    int sum, min_len = INT_MAX;

    for (int i = 0; i < sizeof(arr) / sizeof(arr[0]); i++) {
        subarray.push_back(arr[i]);

        while (accumulate(subarray.begin(), subarray.end(), 0) >= S) {
            min_len = min(min_len, (int)subarray.size());
            subarray.erase(subarray.begin());
        }
    }
    if (min_len == INT_MAX)
        cout << 0 << endl;
    else
        cout << "Minimum length: " << min_len << endl;

}

```


and the complexity for this problem will be the O(N * N) with the constant O(1) space complexity.../.

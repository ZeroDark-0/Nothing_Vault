Given an array of positive numbers and a positive number ‘k’, find the **maximum sum of any contiguous subarray of size ‘k’**.

```
Input: [2, 1, 5, 1, 3, 2], k=3 
Output: 9
Explanation: Subarray with maximum sum is [5, 1, 3].
```

To solve this problem we will be using the siding window while adding the next element and subtracting the k-1 index element until we find the max sum.

```cpp

#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int k = 3;
    int arr[] = {2, 1, 5, 1, 3, 1, 2};
    int n = sizeof(arr) / sizeof(arr[0]);

    int max_sum = 0;
    int curr_sum = 0;

    for (int i = 0; i < k; i++) {
        curr_sum += arr[i];
    }
    max_sum = curr_sum;

    for (int i = k; i < n; i++) {
        curr_sum = curr_sum + arr[i] - arr[i - k];
        max_sum = max(max_sum, curr_sum);
    }

    cout << k << " is: " << max_sum << endl;

    return 0;
}

```


Using this method we will get the complexity of O(N * K) instead of O(N * N).

## <code style="color:red"> DevOps </code>

Why DevOps needed? -> ==to Decrease the delay release and complicated integrated between dev and Ops team==

Before the DevOps, waterfall method was used which delay the release and complicated integration..

### <code style = "color:cyan">Core - Principle:</code>

+ Automation --> Build, Test, Monitor
+ Collaboration --> Dev Q A, DevOps
+ CI/CD --> Pipeline
+ IAC --> Infrastructure as a Code
+ Monitoring --> Code Monitoring 

---

--> Plan -> DevOps Practice

Which software is used for DevOps? ->

JIRA  :-> Jira is ==a project management and issue tracking software used by teams to plan, track, release, and support software==

Agile :-> Agile is ==a flexible approach to project management and software development that emphasizes collaboration, continuous improvement, and adaptability in the face of change==.

Code -> Git aka ==version control== 
GitHub -> Code Repo

CI -> Auto Build + Test
CO -> Auto Deploy + Test
Container -> Docker
Monitory ->==Grafana== (for visualizing and analyzing metrics, logs)

| --------------------------------------------- | -------------------------------------------- |
| Long Release cycle                            | Fast Release Cycle                           |

| Isolated Teams                                | Collaborative                                |

+ Faster to Market -> release roll out very quick
+ Low Failure Rate
+ Faster recovery to Failure
+ High Profit

Use Cases:
+ Startups -> for faster iteration

**Without DevOps** → Engineers keep on redesigning

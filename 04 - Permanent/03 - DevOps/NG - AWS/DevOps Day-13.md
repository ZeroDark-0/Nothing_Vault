# Jenkins

CICD (Open source) -> which mean Continuous Integration/Continues Deployment

Now what is the use of jenkins -> it is for the automate the Building, Deployment, and testing. And it a part of CICD.

- **CI/CD** = Practice/Workflow
    
- **Jenkins** = Tool to automate that workflow

In Jenkins, the "master-slave" or more accurately, "master-agent" architecture ==allows for distributing build jobs across multiple machines, improving efficiency and scalability==. 

And **pipeline in Jenkins** is a set of **automated steps** that define how software moves from **code to production**..

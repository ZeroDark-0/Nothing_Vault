## Enabling a specific language version compiler

```dotnet
<LangVersion>version</LangVersion>
```


the dotnet is divided by the lang version: 
Potential values for the `<LangVersion>` are shown


| `<LangVersion>`            | Description                                              |
| -------------------------- | -------------------------------------------------------- |
| 7,7.1,7.2,7.3,8,9,10,11,12 | manually select the version                              |
| latestmajor                | version 7 in 2019, version 8 in 2019, version 10 in 2020 |
| latest                     | Use the highest version of major and minor               |
| preview                    | it will automatically select the latest preview version  |

To find the version of the compiler:

```dotnet
#error version
```

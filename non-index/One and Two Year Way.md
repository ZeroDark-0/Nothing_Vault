# 🎯 Goal:

To become a job/internship-ready game developer and 3D artist within 1 year by building a strong portfolio that showcases both coding and artistic skills.

# 🗓️ Yearly Roadmap Breakdown

## 📍 Stage 1: Foundations (Month 1–2)

Focus: Learn game programming basics + build confidence with simple games.  
Tools: Unity (C#) or Godot (GDScript)

·        ✅ Milestones:

·        Learn Unity basics (Player movement, physics, collisions)

·        Follow tutorials (Brackeys, Sebastian Lague, Goodgis)

·        Build 1–2 mini projects:

·        • Ball & paddle game (Breakout)

·        • Platformer or Top-down movement demo

·        GitHub repo for code

## 📍 Stage 2: Code + Art Fusion (Month 3–6)

Focus: Combine 3D models with engine work. Start scripting game logic with your own assets.

·        ✅ Milestones:

·        Import custom 3D models (Blender → Unity/Godot)

·        Make interactive objects (doors, pickups)

·        Build a playable 3D mini scene:

·        • Stylized room, forest shrine, or sci-fi corridor

·        Start learning basic UI (menus, health bars)

## 📍 Stage 3: Portfolio Projects (Month 7–10)

Focus: Build polished, unique projects that showcase your strengths.

·        ✅ Milestones:

·        Create a full small game (1–2 levels):

·        • Examples: Puzzle Platformer, Adventure Collect-a-thon

·        Add basic AI (enemy patrol, chase)

·        Use your own environment art, props, or characters

·        Implement polish (UI, audio, feedback effects)

## 📍 Stage 4: Publish & Apply (Month 11–12)

Focus: Final polish, online portfolio, and internship/job hunting.

·        ✅ Milestones:

·        Create a personal website or portfolio page

·        Upload gameplay trailers/gifs/screenshots

·        Post on Itch.io, GitHub, ArtStation

·        Apply to internships or entry-level jobs

·        Participate in 1–2 game jams (Ludum Dare, Brackeys)

# Year 2


# 🎯 Year 2 Goal:

Land a full-time job or freelance/contract work in game development or 3D art — OR build a revenue-generating game/demo.

# 🔷 Year 2 Roadmap (High-Level View)

## ✅ Q1 (Months 1–3): Polish, Share, Apply

🎮 Polish your portfolio: Pick 1–2 of your best projects, refine them.

🌍 Post everywhere: ArtStation, LinkedIn, GitHub, Itch.io, Reddit.

📧 Apply to internships and junior roles: Indie studios, mobile devs, Unity/Unreal engine shops.

🛠️ Join or contribute to an open-source game or modding project.

## ✅ Q2 (Months 4–6): Specialize + Collaborate

🧩 Pick a focus area:

• 3D Environment Art  
• Gameplay Programming  
• Technical Artist / Tools Developer  
• VFX/Shader Artist

👥 Join a small team or collab (Game jam? Small indie group?)

🎯 Start one big “flagship” project: Something you want in your reel.

## ✅ Q3 (Months 7–9): Real Experience

🔁 Freelance / Contract: Try Fiverr, Upwork, or indie game discords.

✨ Participate in 1–2 game jams: Try working in a role you're aiming for.

📸 Make content: Short devlogs, YouTube shorts, breakdowns of your art/code.

## ✅ Q4 (Months 10–12): Ship Something & Go Pro

🚀 Publish something (Itch.io, Steam, Android).

🗃️ Make a game or tool others can use: Asset pack, dev tool, shader.

👔 Apply to full-time jobs:

• Game studios  
• Tech companies (AR/VR, simulations)  
• Remote game dev internships

📝 Prepare for interviews: Solve Unity problems, talk through code/projects, review game math.

# 🎒 Bonus Goals (Optional but Powerful)

• Contribute to a popular GitHub game repo.

• Make a dev blog or Notion resume.

• Get feedback from a senior dev/artist (LinkedIn, Reddit).

• Learn Unreal Engine 5 or build your own small engine framework.

# 🎤 TL;DR:

Year 1 = Build skills + portfolio

Year 2 = Polish + specialize + ship real things + apply everywhere

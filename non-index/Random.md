Goal:
Build a fully automated CI/CD pipeline that:
Uses AWS CodeCommit as the Git repository
Builds code with AWS CodeBuild
Deploys a static website to Amazon S3

You want to build and automatically deploy a static website (e.g., a React, Vue, or HTML/CSS/JS app) every time you push changes to a Git repo.
